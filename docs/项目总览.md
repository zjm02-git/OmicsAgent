# 项目总览（简洁完整版）

> 一页看完整个项目：它是什么、怎么跑、有哪些模块、用了什么算法。
> 适合面试前 5 分钟快速回顾，或给别人一句话介绍。

---

## 一、一句话定位

用 **LangGraph** 把「基因表达差异分析 + 通路富集」编排成 8 个节点的图：
**LLM 负责理解和解读，Python 负责质检和统计**，中间用条件边路由、用检查点断点续跑、用人工确认把关、用长期记忆记住偏好、用回溯换参重跑，自动产出一份带解读的分析报告；已用真实数据（TCGA-BRCA 226 样本）验证可落地。

---

## 二、架构图

```
用户："帮我找两组样本的差异表达基因，并解读"
        │
        ▼
[① parse_intent]   结构化输出 → 判断分析类型（differential / other）
        │
        ├── other ──────────► [⑧ report] 出"暂不支持"报告
        ▼ differential
[② load_qc]        读数据 + 质检（文件/分组/样本数/缺失值）+ 读长期记忆阈值
        │
        ├── 不合格 ──────────► [⑧ report] 出"质检失败"报告
        ▼ 合格
[③ human_review]   interrupt 暂停，等人工批准 / 取消
        │
        ├── 取消 ────────────► [⑧ report] 出"已取消"报告
        ▼ 批准
[④ diff_analysis]  差异表达：t 检验 + log2FC + BH 校正
        │
        ▼
[⑤ enrichment]     通路富集：超几何检验 + BH 校正
        │
        ▼
[⑥ interpret]      LLM 把基因列表 + 富集通路解读成人话
        │
        ▼
[⑦ save_memory]    把本次阈值偏好写回长期记忆
        │
        ▼
[⑧ report]         汇总成 Markdown 报告
        │
        ▼
       END
```

## 三、八个节点（一句话职责）

| 节点 | 谁干 | 一句话 |
| --- | --- | --- |
| ① parse_intent | LLM | 把用户的人话变成确定的分析类型 |
| ② load_qc | Python | 读数据 + 质检，读长期记忆里的阈值偏好 |
| ③ human_review | 系统 | 暂停等人工确认，可批准或取消 |
| ④ diff_analysis | Python | 真算：找显著差异表达基因 |
| ⑤ enrichment | Python | 真算：判断显著基因扎堆在哪些通路 |
| ⑥ interpret | LLM | 把数字翻译成生物学解读 |
| ⑦ save_memory | 系统 | 把本次阈值偏好写回长期记忆 |
| ⑧ report | Python | 汇总成完整 Markdown 报告 |

**核心分工**：LLM 干"懂"的活（①⑥），Python 干"算"的活（②④⑤⑧），系统干"把关 + 记忆"的活（③⑦）。

## 五、快速开始

```bash
pip install -r requirements.txt   # 1. 装依赖
# 2. 准备数据（二选一，格式一样、代码不用改）
python data/generate_data.py      #    模拟数据：100 基因 × 8 样本，开箱即用
python data/fetch_tcga.py         #    真实数据：TCGA-BRCA 226 样本 × 2 万基因（约 10 分钟）
python data/fetch_go.py           #    真实数据再补 GO 注释
python app.py --auto              # 3. 跑一次完整分析（--auto 跳过人工确认）
```

`.env` 里填 `DEEPSEEK_API_KEY`（模板见 `.env.example`）；想启用 PostgreSQL 持久化再设 `USE_POSTGRES=true`。

## 六、两个核心算法（各一句话）

- **差异表达分析**：对每个基因算 log2FC（差多少倍）、Welch t 检验的 p 值（可不可信）、BH 校正后的 FDR（多重检验校正），三者都满足才算显著。
- **通路富集分析**：用超几何检验（抽球模型）判断显著基因是否"扎堆"在某通路，同样做 BH 校正。

## 八、核心亮点（面试讲的点）

1. **图编排**：多步骤流水线显式画成节点 + 边，可读可维护可扩展；
2. **结构化输出路由**：让 LLM 输出确定值而不是自由文本，路由才可靠；
3. **条件边**：质检不合格自动走失败分支，流程自己会拐弯；
4. **检查点持久化**：每个节点跑完存档，InMemorySaver / PostgresSaver 可切换，重启不丢；
5. **Human-in-the-loop**：质检后 interrupt 暂停等人工确认，关键步骤可把关；
6. **长期记忆**：PostgresStore 记住用户阈值偏好，下次自动复用；
7. **真实统计计算**：差异分析和富集分析都是真算，不靠 LLM 编；
8. **LLM 结果解读**：数字翻译成人话，结果可解释；
9. **回溯（时间旅行）**：get_state_history 列检查点 + update_state 换参数，回到历史点重跑不从头来；
10. **真实数据验证**：接入 TCGA-BRCA（226 样本 × 2 万基因），跑出 2801 个显著差异基因，证明能落地。
